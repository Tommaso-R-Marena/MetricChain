# Workstream R2 — scripts and outputs of review SCI-REV-0002 (theory report §11.22)

Report: `docs/science/workstreams/R2_REPORT.md`.  Running log: `NOTES.md`.  Everything here was written
by the reviewer; the enumerators and tests were written **before** reading the authors' or the
engineering division's code.  Outputs are in `out/`.  Python 3.13, numpy, scipy (HiGHS); gcc.

Build: `mkdir -p bin; gcc -O3 -march=native -o bin/r2_enum r2_enum.c; gcc -O3 -march=native -o bin/r2_concat r2_concat.c`
