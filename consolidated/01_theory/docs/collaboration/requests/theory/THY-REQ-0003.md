# Does a physically motivated residual have a useful constant in the profile format?

## Scientific context

The theory says that a residual `g = E − E₀` is cheap to certify if it is *linear in known
features with a small sup-norm remainder*: `g(x) = Σ_τ Σ_{p<q of type τ} φ_τ(s_pq(x)) + ρ(x)` with unknown
radial functions `φ_τ` that are `L`-Lipschitz in the squared distance `s` and vanish beyond a cutoff,
and `|ρ| ≤ η`.  Then every linear combination of evaluations brackets `g` at a new conformation
`y` by `L·‖N^y − Σ_i λ_i N^{x_i}‖_{L¹} + η(1 + ‖λ‖₁)` (`pairRes_span_upper` **[V]**; the `η`-term is Theorem 13 of
the workstream report, **[P]** reviewed).  The theory report ends this topic with the
sentence: *"Whether a given physical residual lies in such a class with a useful `L` is an
empirical question that this report does not address."*  Until one instance is examined, the
interface is hypothetical.

## Question

For synthetic chain models in which both `E₀` and `E` are computable, what is the trade-off
curve `η*(L)` — the smallest sup-norm remainder with which the residual lies in `P_L + {|ρ| ≤ η}` —
and how many evaluations does the span bracket then need to predict the residual on unseen
conformations to a given accuracy, as a function of chain length?

## Suggested inputs (synthetic chains only)

Chain models of the kind already used: rotamer chains with fixed bond length and angle, or
bead–spring chains, `N = 12 … 64` beads, one to three bead types in a **made-up, fixed** sequence;
conformations from enumeration (short) or self-avoiding Monte Carlo (long).  Pairs
`(E₀, E)` of increasing difficulty:

1. *Inside the class by construction*: `E₀` and `E` pair-additive with different smooth radial
   functions (e.g. two Lennard-Jones-type or Morse-type curves truncated and shifted).  Then
   `η* = 0` at `L = sup|φ′_E − φ′_{E₀}|` — the question is how large that `L` is in the squared-distance
   variable when the short-range wall differs, and how the certificate count behaves.
2. *A non-pair-additive correction*: `E = E₀ +` a three-body term (Axilrod–Teller form, or a
   bond-angle term between non-bonded neighbours) or a solvent-like term depending on a
   coordination number.
3. *A learned residual*: `E` from a small neural potential trained on data generated by (1) or
   (2) — the case in which nobody knows a priori what class the error belongs to.

No biological sequences, no design or optimisation of sequences, no experimental data.

## Proposed computational approach

For a sample `X` of conformations compute the cumulative profiles on a grid of squared
distances (features) and solve the linear programme

    minimise η   subject to   |g(x) − Σ_{τ,k} ψ_{τ,k} · Δ_k · N^x_τ(s_k)| ≤ η  for x ∈ X,   |ψ_{τ,k}| ≤ L

for a range of `L` (the `ψ` are the slopes `−φ′`); this gives `η*(L)` on the sample, to be
validated on held-out conformations.  Then, for chosen `(L, η)`: greedy selection of
evaluation points by the span bracket (maximise the current width over a pool), the number
of evaluations needed for width `≤ ε₁N` on the pool, against `N`; the same with the first-order
covering in `d_P` for comparison.

## Expected outputs

`η*(L)` curves per model and chain length (train and held-out); the certificate counts
against `N`; the rank and conditioning of the profile feature matrix; a statement of how the
required `L` scales with the short-range steepness of the potentials.

## Resource requirements and runtime

LPs with `|X|` up to `10⁴–10⁵` rows and a few hundred columns: seconds to minutes each on CPU.
Sampling long chains and training the small potential of case 3: CPU-hours, or a single
GPU for the training.  This is a modest job; the value is in the design, not the scale.

## Suggested validation protocol

Case 1 is the negative control: the LP must return `η* = 0` (to solver tolerance) at the
analytic `L` and `η* > 0` below it; the span bracket must contain the true value on every
held-out conformation (a violation means a bug or a sample that does not represent the
domain).  Harness XIV.1, XIV.2 are executable references for the brackets.

## Stopping conditions

Three models and four chain lengths are enough for a first answer.  Stop early if case 1
already requires an `L` so large that the bracket is wider than the range of `g` — that is the
answer "not useful for hard-core potentials without moving the wall into `E₀`", and it should
be reported as such.

## What the possible outcomes would mean

* *Small `η*` at moderate `L`, counts flat in `N`*: the profile format is a real interface for
  certified residual models; the theory division would work on the checking cost (open
  question 9(d)) and on a limit theorem.
* *`L` must be huge because of the repulsive wall*: the known part must absorb the short
  range; the right class is "Lipschitz beyond a core radius", and the theory needs a version
  with a distance-dependent `L(s)` (the Lean statements already allow a grid-dependent
  weight; the report does not exploit it).
* *Large `η*` for learned residuals*: principle 2 of THY-MSG-0002 is true and not useful
  without an architecture that enforces the class (see that message).

## Assumptions and limitations

Synthetic models; a sample of conformations certifies nothing about the full domain — the
numbers are estimates of the class parameters, not guarantees.

## Requested response

`ENG-RES` with the curves and counts, or a decline.  A negative result is as useful as a
positive one.
