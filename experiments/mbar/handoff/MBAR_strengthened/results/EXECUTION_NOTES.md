# Execution evidence and limitations

Final `test_and_benchmark.py` run completed, with terminal marker `ALL REFERENCE CHECKS PASSED` and JSON output. Seed 20261128. The first run intentionally retained its error: BFGS residual 2.18e-9 exceeded an excessively strict 1e-9 threshold; rerun used 1e-7 and an explicit pilot fallback if a solver failed (zero fallbacks in the final 600 tests). The second run failed in a minimax numerical check: generic np.linalg.pinv(L) could invert a spurious roundoff-scale gauge eigenvalue. Final tests solve on the explicitly projected gauge instead, consistent with the theorem. No failed experiments were dropped from final coverage. Logs of failed runs retained; source now uses the corrected numerical method. The independent minimax run uses a separately restarted fixed seed and 1000 checks; the final combined run tests another 1000 instances.

All experiments use synthetic discrete probability models. The optimization results are population asymptotic variance, not empirical simulation RMSE or GPU savings. The allocation problem uses fixed restricted simplex s_k>=0.02. The reported median reductions compare objective values on the same 60 models. The pilot vector in coverage tests is generated independently as truth plus noise; it is not a learned molecular pilot and should not be interpreted as practical deployment validation. All six coverage regimes contain 100 trials; the bridge test has simultaneous noncoverage count 0/600 and all intervals finite; cut-score test has noncoverage 0/600 with 200 abstentions (two low-overlap regimes) and 400 finite radii. Coverage is intentionally conservative; e.g. width ~8.85 reduced energy units for the weakest 100-per-state case. The proofs, not empirical zero failures, justify the stated probability bounds subject to assumptions.

The new C3, G1, G2, E2, E3 extensions have not yet been implemented or benchmarked. No formalization or statistical coverage claim beyond what is directly reported. New code uses float64 and is a reference, not production-certified interval arithmetic. `cut_radius` taking O assumes exact stationarity; use `observable_cut_radius` for numerical candidate fits. `graph_diagnostic` is deliberately only a diagnostic, not a guarantee of population accuracy.
