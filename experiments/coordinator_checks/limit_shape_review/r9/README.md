# Verification of Theorem R9.1 of the Scientific Discovery Division (bridges: the concatenation error is a coboundary)

The theorem is stated and proved in `docs/science/workstreams/R9_REPORT.md` §4 on the branch
`research/scientific-translation` (review SCI-REV-0009, §4; follow-up SCI-REV-0011).  It is
adopted, attributed, as Proposition 11.69b of the theory report (§11.22).  Before adoption
parts (a)–(e), the volume bound and the nine text points of the review were verified here
by an independent assistant with code written from the *Setting* of §11.22 and from the
definitions of the theorem, before the division's code was opened.  **Nothing in this
directory is imported from that division.**  From our own repository only `../mylat.py`
(lattice, enumeration, the two profile counts) and, for the ten explicit bridges, the
builder of workstream S are used.

| file | what it is |
|---|---|
| `v9_cobound.c` | the main verifier: every quantity counted by plain double loops over pairs of beads from coordinates.  Modes `pairs`, `pairs2` (all ordered pairs of bridges: the three identities of (a), exact additivity and cleanliness for clean pairs (b)), `single` (every pair (bridge, admissible bond): cleaning by head 2 + tail 3 and five other head/tail variants (c), the maxima of `A` and `B`).  Six mutation switches (`-DMUT=1..6`), each of which must make the run report failures.  Build: `gcc -O3 -march=native -fopenmp v9_cobound.c -o v9_cobound`; plain-loop reference build: `gcc -O2 -DREF -fopenmp` |
| `v9_lib.py` | a second implementation in Python (look-up of displacements instead of double loops) |
| `v9_py_check.py DUMP NP NRAND SEED` | the C program's per-bridge data against the Python counts; all ordered pairs with at most `NP` beads **without** fixing the first bonds (both sublattices); random long bridges (cleaning, random concatenations, six-fold self-concatenations).  `DUMP` is the standard output of `v9_cobound single 12 12 3 11` |
| `v9_lattice.py DUMP` | part (e): integer row reduction of the vectors `(h₃, h₈, h₁₁, g; N+3)` of the clean bridges; the division's five vectors; unimodular five-subsets with the fewest beads |
| `v9_extremal.py OUT_SINGLE` | part (d): the pair of bridges with 21 and 14 beads whose concatenation has the error `(1, 9, 14; 1)`, norm 60, from coordinates; the arithmetic of `108` |
| `v9_gen_witness.py OUTDIR W key …`, `v9_volume.py WITDIR` | the ten explicit bridges of §11.22 rebuilt with our builder; their end corrections `A`, `B`; exact hull volume of the fourteen exact profile points (no hull code; and Qhull's facet list with exact arithmetic): `1.631346`; the four packings with all radii zero |
| `out_*.txt` | the outputs of the runs cited in the theory report (sizes up to 14 beads for pairs, 22 beads for single bridges; these took 5 to 12 minutes each on three threads) |

Sizes of the stored runs: `out_pairs_13.txt` (all pairs with `N₁, N₂ ≤ 13`: 350 026 681 ordered
pairs, the division's count), `out_pairs2_14_12.txt`, `out_pairs2_12_14.txt`,
`out_pairs2_14_14_rest.txt` (together with the first: all 2 548 937 169 ordered pairs with
`N₁, N₂ ≤ 14`, 0 failures), `out_pairs2_16_8.txt`, `out_pairs2_8_16.txt`, `out_pairs_full10.txt` (both
sublattices, all first bonds, `N ≤ 10`), `out_pairs_ref12.txt` (plain-loop build), `out_single_22.txt`
(all 162 418 271 pairs (bridge, bond) with at most 22 beads), `out_single_20.txt`,
`out_mutations.txt`, `out_py_check.txt`, `out_lattice.txt`, `out_extremal.txt`,
`out_their_certificate_check.txt` (the division's five bridges verified from coordinates),
`out_volume.txt`, `out_gen_W64.txt`, `out_gen_W128.txt`.

A quick reproduction (two minutes; done again by the coordinator from this directory when
the files were stored): `v9_cobound pairs 11 reduced 3` — 6 869 641 ordered pairs, 0 failures,
error maxima `(0, 4, 6; 1)`; `v9_cobound single 12 12 3 11 > dump.txt` — head 2 + tail 3 always
clean, head 1 fails first at 8 beads, tail 2 first at 12; `python3 -B v9_py_check.py dump.txt 6 150 1`;
`python3 -B v9_lattice.py dump.txt` — rank 4 up to 9 beads, index 1 from 10 beads on.

**Not verified here:** parts (f) (interior saturation) and (g) (counting) of the theorem
beyond a reading and a re-derivation of Khovanskii's lemma.  Nothing is machine-checked.
The binary and the dump file (`D …` lines, 300 kB) are not stored; both are regenerated by
the commands above.
